Supprimer son compte Tult

Comment effacer votre compte et vos données en ligne

English version

Depuis l’application

  • Ouvrez Tult et touchez la roue dentée pour aller dans les Réglages.
  • Dans la section Compte, choisissez Supprimer mon compte.
  • Confirmez. La suppression est immédiate.

Sans l’application

Si vous n’avez plus l’application, écrivez à jointultapp@gmail.com avec pour objet « Suppression de compte », depuis l’adresse e-mail reliée à votre compte, ou en indiquant votre code ami (par exemple Max#4821). Le compte est supprimé dans un délai de 30 jours, et vous recevez une confirmation.

Ce qui est supprimé

  • Votre profil : nom, couleur, emoji, code ami et photo de profil.
  • L’adresse e-mail ou le compte Google relié.
  • Votre liste d’amis.
  • Les joueurs, parties et tournois enregistrés en ligne depuis votre téléphone.
  • Les liens d’invités et les parties que vous aviez retirées de vos statistiques.

Ce qui est conservé

Les parties jouées avec des personnes qui ont elles aussi un compte restent dans leurs statistiques, sans lien avec votre compte. Les copies de sécurité techniques de l’hébergeur, s’il en existe, s’effacent au fil de leur renouvellement.

Les données enregistrées sur votre téléphone ne sont pas touchées : pour les effacer, utilisez « Effacer toutes les données » dans les réglages, ou désinstallez l’application. Le détail figure dans la politique de confidentialité.
